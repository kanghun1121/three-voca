# Claude 명령어: Commit

`[Type]` 태그 기반 커밋 메시지로 잘 포맷된 커밋을 생성합니다. 이모지는 사용하지 않습니다.

## 사용법

```
/commit
```

## 프로세스

1. 스테이지된 파일 확인, 스테이지된 파일이 있으면 해당 파일만 커밋
2. 여러 논리적 변경사항에 대한 diff 분석
3. 필요시 분할 제안
4. `[Type]` 포맷으로 커밋 생성

## 커밋 포맷

`[<Type>] <설명>`

**타입** (PR 제목의 Type과 동일):

- `Feature`: 새로운 기능
- `Fix`: 버그 수정
- `Refactor`: 코드 리팩토링
- `Chore`: 빌드/도구/설정
- `Docs`: 문서화

**규칙:**

- 이모지 사용 금지
- 이슈 번호는 커밋 메시지에 넣지 않는다 (PR 제목의 `[T-<번호>]`에만 사용)
- 설명은 한국어, 명령형 어조 ("추가" not "추가됨")
- 첫 줄 72자 미만
- 원자적 커밋 (단일 목적)
- 관련 없는 변경사항 분할

## 예시

```
[Feature] 어휘 검색 필터 추가
[Fix] 로그인 후 세션 만료 처리 수정
[Chore] Shared 제거 마무리
```

## 분할 기준

다른 관심사 | 혼합된 타입 | 파일 패턴 | 큰 변경사항

## 참고사항

- 스테이지된 파일이 있으면 해당 파일만 커밋
- 분할 제안을 위한 diff 분석
- **커밋에 Claude 서명 절대 추가하지 않음**
