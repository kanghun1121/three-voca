# harness-implementation

## Goal

Implement the approved plan with minimal, disciplined code changes and verify the result.

## Rules

- 승인된 책임 범위를 따를 것
- 구현을 작게 유지할 것
- 불필요한 추상화를 추가하지 말 것
- 테스트의 의도를 변경하지 말 것
- 구현 후 검증 명령을 실행할 것
- 테스트가 실패하면, 코드를 수정하기 전에 어떤 요구사항이 실패했는지 설명할 것
- 이 저장소 외부의 파일을 수정하지 말 것
