# harness-test

## Goal

After implementation is complete, cover it with the following tests.

- 정상 케이스 (Happy path)
- 빈 입력 (Empty input)
- 잘못된 입력 (Invalid input)
- 권한 실패 (Permission denied)
- 중복 처리 (Duplicate request)
- 없는 데이터 (Missing data)
- 상태 변경 확인 (State change verification)
- 경계값 (Boundary case)
