# swift-dependencies — pointfreeco/swift-dependencies
# https://github.com/pointfreeco/swift-dependencies

## 핵심 개념

의존성은 세 값으로 정의된다:
- `liveValue`: 프로덕션 구현 (네트워크, DB 등 실제 외부 호출)
- `testValue`: 테스트 구현. `unimplemented()`로 감싸 의도치 않은 호출 시 즉시 실패
- `previewValue`: SwiftUI Preview / Example 앱용 고정 Fixture

## Repository / UseCase 정의 패턴

이 프로젝트는 Repository(포트)와 UseCase(ViewModel이 호출하는 단위)를 분리한다. 자세한 설명은
`docs/ARCHITECTURE.md`의 "Repository / UseCase 패턴" 참고.

```swift
// Repository — DomainInterface 타겟, Domain/Interface/Repository/HomeRepository.swift
struct HomeRepository: Sendable {
    var fetchHomeOverview: @Sendable () async throws -> VocabularyLibrary
}

extension HomeRepository: TestDependencyKey {
    static let testValue = HomeRepository(
        fetchHomeOverview: unimplemented("\(Self.self).fetchHomeOverview")
    )
    // previewValue 없음 — Repository는 ViewModel이 직접 참조하지 않는다
}

extension DependencyValues {
    var homeRepository: HomeRepository {
        get { self[HomeRepository.self] }
        set { self[HomeRepository.self] = newValue }
    }
}

// Repository의 liveValue — Data 타겟, Data/Sources/Home/HomeRepository+Live.swift
extension HomeRepository: DependencyKey {
    static let liveValue = HomeRepository(
        fetchHomeOverview: { /* Supabase 실제 호출 */ }
    )
}
```

```swift
// UseCase — DomainInterface 타겟, Domain/Interface/UseCase/GetHomeOverviewUseCase.swift
struct GetHomeOverviewUseCase: Sendable {
    var execute: @Sendable () async throws -> VocabularyLibrary
}

extension GetHomeOverviewUseCase: TestDependencyKey {
    static let testValue = GetHomeOverviewUseCase(
        execute: unimplemented("\(Self.self).execute")
    )
    static let previewValue = GetHomeOverviewUseCase(
        execute: { .previewFixture }
    )
}

extension DependencyValues {
    var getHomeOverviewUseCase: GetHomeOverviewUseCase {
        get { self[GetHomeOverviewUseCase.self] }
        set { self[GetHomeOverviewUseCase.self] = newValue }
    }
}

// UseCase의 liveValue — Domain 타겟, Domain/Sources/UseCase/GetHomeOverviewUseCase+Live.swift
extension GetHomeOverviewUseCase: DependencyKey {
    static let liveValue = GetHomeOverviewUseCase(
        execute: {
            @Dependency(\.homeRepository) var homeRepository
            return try await homeRepository.fetchHomeOverview()
        }
    )
}
```

## ViewModel에서 사용

ViewModel은 Repository가 아닌 **UseCase만** `@Dependency`로 주입받는다.

```swift
@Observable
@MainActor
final class HomeViewModel {
    @ObservationIgnored
    @Dependency(\.getHomeOverviewUseCase) private var getHomeOverviewUseCase
}
```

`@ObservationIgnored` 필수 — `@Observable` 매크로와 `@Dependency`의 프로퍼티 래퍼 충돌 방지.

## 테스트에서 재정의

```swift
func testLoad() async throws {
    let model = withDependencies {
        $0.getHomeOverviewUseCase.execute = { .previewFixture }
    } operation: {
        HomeViewModel()
    }
    await model.load()
    #expect(model.state != nil)
}
```

## liveValue vs DependencyKey vs TestDependencyKey

| 프로토콜 | 제공하는 값 | Repository 사용 위치 | UseCase 사용 위치 |
|---|---|---|---|
| `DependencyKey` | `liveValue` | `Data` 타겟 | `Domain` 타겟 |
| `TestDependencyKey` | `testValue`, `previewValue` | `DomainInterface` 타겟(testValue만) | `DomainInterface` 타겟 |

Repository/UseCase 모두 Interface(`DomainInterface`)에서 struct 선언 + `TestDependencyKey`를 정의하고,
Implements(Repository는 `Data`, UseCase는 `Domain`)에서 `DependencyKey`(`liveValue`)를 확장으로 추가한다.
