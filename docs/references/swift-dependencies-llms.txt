# swift-dependencies — pointfreeco/swift-dependencies
# https://github.com/pointfreeco/swift-dependencies

## 핵심 개념

의존성은 세 값으로 정의된다:
- `liveValue`: 프로덕션 구현 (네트워크, DB 등 실제 외부 호출)
- `testValue`: 테스트 구현. `unimplemented()`로 감싸 의도치 않은 호출 시 즉시 실패
- `previewValue`: SwiftUI Preview / Example 앱용 고정 Fixture

## Client 정의 패턴

```swift
// DomainInterface 타겟에 선언
struct HomeClient: Sendable {
    var fetchHomeOverview: @Sendable () async throws -> VocabularyLibrary
}

extension HomeClient: DependencyKey {
    static let liveValue = HomeClient(
        fetchHomeOverview: { /* Supabase 실제 호출 */ }
    )
}

extension HomeClient: TestDependencyKey {
    static let testValue = HomeClient(
        fetchHomeOverview: unimplemented("\(Self.self).fetchHomeOverview")
    )
    static let previewValue = HomeClient(
        fetchHomeOverview: { .previewFixture }
    )
}

extension DependencyValues {
    var homeClient: HomeClient {
        get { self[HomeClient.self] }
        set { self[HomeClient.self] = newValue }
    }
}
```

## ViewModel에서 사용

```swift
@Observable
@MainActor
final class HomeViewModel {
    @ObservationIgnored
    @Dependency(\.homeClient) private var homeClient
}
```

`@ObservationIgnored` 필수 — `@Observable` 매크로와 `@Dependency`의 프로퍼티 래퍼 충돌 방지.

## 테스트에서 재정의

```swift
func testLoad() async throws {
    let model = withDependencies {
        $0.homeClient.fetchHomeOverview = { .previewFixture }
    } operation: {
        HomeViewModel()
    }
    await model.load()
    #expect(model.state != nil)
}
```

## liveValue vs DependencyKey vs TestDependencyKey

| 프로토콜 | 제공하는 값 | 사용 위치 |
|---|---|---|
| `DependencyKey` | `liveValue` | Domain Implements 타겟 |
| `TestDependencyKey` | `testValue`, `previewValue` | DomainInterface 타겟 |

이 프로젝트에서는 Interface/Implements 분리 구조 때문에 두 프로토콜을 나눠서 선언한다.
`DependencyKey`는 `Domain` 타겟, `TestDependencyKey`는 `DomainInterface` 타겟.
