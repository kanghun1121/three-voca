# OEC-MAINTAIN: 테스트와 유지보수 비용

적용: 테스트만을 위한 제품 코드, 공개 API, 사용되지 않는 옵션·상태 또는 큰 Mock 계층이 추가된 경우.

- [ ] 단순한 동작을 검증하려고 테스트 전용 추상화나 큰 Mock 계층을 새로 만들었는가?
- [ ] 호출자가 사용하지 않는 옵션·상태·공개 API 때문에 구현 분기와 테스트가 늘었는가?
- [ ] 기존 의존성 주입 경로로 검증할 수 있는데 테스트 전용 제품 코드 경로가 추가됐는가?

실제 실패 경로를 검증하는 테스트와 안전한 대체 지점은 보존한다. 테스트가 중요하다는 사실과 테스트를 위해 만든 모든 구조가 필요하다는 판단은 구분한다. 테스트의 결함 탐지력 자체는 `test-value-check`로 확인한다.
