# TVC-ASYNC: 비동기 테스트 안정성

적용: 비동기 작업 대기, 고정 지연, 시간·UUID·외부 시스템 의존이 변경된 경우.

- [ ] 작업 완료나 기대 이벤트를 확인한 후 단언하는가? `Task.sleep`이 단지 시간을 벌어 우연한 성공에 의존하지 않는가?
- [ ] 스트림처럼 끝나지 않는 작업이라면 작업 전체 종료 대신 필요한 이벤트를 기다리는가?
- [ ] 시간·UUID·네트워크·파일·DB 상태를 검증 범위에 맞게 제어하고 테스트 간 공유를 피하는가?

고정 지연 자체가 테스트 대상이거나 허용 오차를 검증한다면 시간 기반 대기가 필요할 수 있다. 일반적인 상태 전이 검증이라면 관찰 가능한 완료 조건을 사용한다.
