# TVC-VALUE: 테스트의 필요성과 중복

적용: 테스트가 추가·복제되거나 테스트의 목적과 검증 범위가 바뀐 경우.

- [ ] 사용자 경험, 도메인 규칙, 데이터 보존, 경계 계약 또는 회귀 위험에 연결되는가?
- [ ] 다른 테스트와 입력·실행 경로·기대 결과가 같아 추가 결함을 발견하지 못하는가?
- [ ] 첫 항목 선택·정렬 등 여러 입력의 차이가 핵심인데 한 항목이나 같은 값만 사용하지 않는가? 이때 `TVC-ASSERT`도 함께 확인한다.
- [ ] 한 줄 구현이나 언어 기능을 반복 확인하기 위해 준비·유지 비용만 늘리는가?

동일해 보이는 테스트도 서로 다른 실패 경로나 계약을 검증한다면 유지할 가치가 있다. 중복만으로 단정하지 말고 각 테스트를 제거했을 때 놓치는 결함을 비교한다.
